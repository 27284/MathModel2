# V3 实施约定与验收

依据同目录 `MathModel2_第二问_V3完整优化方案.md`。所有旧输出保留，新增输出写入 `outputs/results_v3`。冻结文件 `data.py`、`preprocess.py`、`config.py` 以及四份 MAT 的哈希在运行时核验；333 Trial 的主分类 OOF 标签、折号、预测和概率与原结果逐条核对。

## 实施映射

1. **slow.py**：none / linear / quadratic / natural_spline_df4；逐记录、逐通道，节点及标准化只使用训练绝对时间。采用 -1 至 -0.2 s 原始刺激前样本识别实验漂移，避免把刺激锁定 ERP 强制解释为漂移。预测先计算 S(T+t)，再减去本 Trial 刺激前均值，与既有观测坐标一致。该选择保留第一问处理，可能使可识别慢趋势贡献很小；这是模型限制而非省略慢趋势。
2. **basis.py**：Common 为 q/LP80/LP250；Contrast 为 q/LP80；两个 family 可有不同列数。独立 ridge 网格均为 0.1/0.01/0.001。persistent step 不进入神经基底。LP750 为单独消融。
3. **形变**：Base、Base±40 ms、Base±80 ms、Base+stretch(0.7/1.4)、Base+两档 shift+stretch；不建立 shift×stretch 全笛卡尔积。先在 padded 时间网格变换，再原低通和基线校正。基底 RMS 仅来自模拟波形与训练 duration，未读取 EEG。
4. **嵌套阶梯**：M1/M2 各自搜索 slow×耦合 ridge；M3 固定 M2 的 slow/ridge，仅选形变；M4 固定 M3 的 slow/形变，搜索独立 λC、λD；M5 固定 M4 的结构，搜索 λG。每次拟合和内层验证均排除外层测试块。该流程是受控的分阶段搜索，不声称完成全组合最优搜索。
5. **pooling**：阶梯固定 pool=0；另报告 M4 在 pool=0/0.1/1 的配对消融及 training-only 内层选 pool；不根据外层最佳 pool 替换主结果。
6. **forward.py**：两源→三电极；对称 G=[[a0,a0],[a1,a2],[a2,a1]]。先将训练自由读出投影到固定 G0 对应源坐标，再估计 G；G0+ΔG 带惩罚作为独立消融。第一阶段源坐标固定后再拟合 G，因此不同时任意调整源尺度。源系数仍由训练 WC 基底生成。effective_linear_df_free_stage 仅报告第一阶段线性自由度，未伪称完整两阶段非线性自由度。G0 为示意偶极几何，不是测量头模型。
7. **nuisance.py**：训练-only ECG-like 核验包括周期性峰间隔、波形一致性、候选心搏触发 EEG；ECG-like 通过不等于临床 ECG 认证，也不证明污染因果。QC 和 trial_index 回归均仅训练拟合；ECG 未通过时 ECG/all 不运行并保存状态。主分类不受门槛影响。
8. **置换**：主分类默认 200 次，ECG 敏感性默认独立 200 次；分别使用 seed+10000+i 与 seed+20000+i；记录×原时间块内置换。每次重训 LR 及特征标准化；可复用与标签无关且仅训练拟合的 nuisance 变换。ECG 覆盖不足则不做全体 ECG 显著性检验。

## 计分和审计

共同目标为原轻处理的 QC×Huber heldout 条件 ERP。慢趋势使用训练 QC 系数加权，响应预测为神经 ERP 加测试已知 onsets 对应的慢趋势均值。神经拟合目标为训练去慢趋势后的 QC×Huber ERP。Huber 非线性导致“残余 ERP 的 Huber 均值”和“观测 ERP 减均值慢趋势”不必完全相同；分解图使用后者，保证图上 observed = slow + residual。

所有候选使用相同窗口：0–800、0–500、250–500、600–800 ms；沿用既有实际采样网格的末点和端点约定。按条件数组分别计算 joint、Common=(R+L)/2、Contrast=(R−L)/2；不同 fold/record 的 SST 不重新跨折中心化。pooled R²=1−ΣSSE/ΣSST，RMSE=√(ΣSSE/Σ元素数)。逐折差值以同一模板为基准，ΔSSE=SSE_template−SSE_model。

测试标签只用于分条件计算评估 ERP，不用于估计参数；条件生成不是分类器。预测神经 ERP 的 cue duration 固定为训练中位数。内层目标为训练通道尺度归一化的核心窗 joint+Contrast 误差；不依据外层成绩调整窗口或基底。

测试包含：原有 V2 回归测试、慢趋势绝对时间和基线约定、自然样条线性外推、shift/stretch 定义、对称 G 的合成恢复、几何惩罚、C/D 正则独立性、测试块信号/标签/onset/QC 污染不改变训练拟合、主分类逐条复现、内层最小损失选择、相同计分目标、pooled 与配对差值核验。V2 历史归档验收验证其原输出指纹；V3 的代码指纹另行验证。

## 停止规则

如 M5 的 heldout 250–500 ms R²<0 且不优于 M0，停止加复杂度并报告限制；不会为了把指标变正而使用外层结果继续调参。正式数值以新结果报告为准。若空间约束降低预测表现，仍如实保留其消融结果。
